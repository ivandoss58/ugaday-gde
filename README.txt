# Угадай где — веб-версия игры

## Логика экранов

1. При открытии сайта показывается только стартовый экран.
2. Изображение стартового экрана автоматически занимает весь viewport без прокрутки и без искажения пропорций.
3. Страница выбора разделов открывается только после нажатия «Играть».
4. Кнопка × внутри игры возвращает к выбору разделов.
5. В каждом разделе 4 страницы по 4 пары.
6. При запуске раздела случайно выбираются 16 пар из доступного набора.

## Текущие разделы

- Грибы — 16 пар.
- Животный мир морей и океанов — 20 пар, из которых случайно выбираются 16.

Остальные категории добавляются после загрузки соответствующих изображений.

## Стартовая картинка

Сейчас используется:
images/game-cover.jpg

images/game-cover-mobile.jpg
images/game-cover-desktop.jpg
