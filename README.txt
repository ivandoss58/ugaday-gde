# Угадай где — прототип

Откройте `index.html` в браузере.

В проекте:
- 4 пары название/изображение;
- случайная перестановка карточек;
- выбор названия и изображения;
- зелёная рамка при правильном совпадении;
- красная рамка при ошибке;
- 3 жизни;
- индикатор прогресса;
- кнопка «Далее» после завершения;
- адаптация под вертикальный экран телефона.

Тестовые изображения находятся в папке `images/` и не требуют интернета.
